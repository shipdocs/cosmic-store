# Kompas 0.1.0 — first public preview

Kompas brings applications from your configured Zorin/Ubuntu repositories, Flatpak
remotes and Steam discovery into one interface. This is a preview for testing on
Zorin 18 / Ubuntu 24.04, on 64-bit Intel/AMD computers.

## Included

- Unified search, source filters, categories and subcategories.
- Native Linux filtering, enabled by default.
- Games sorted by original release date, with unknown dates last.
- Back navigation, English default UI and Dutch translations.
- Independent Kompas branding, icons and app identity.
- Clear AppStream metadata and screenshots for the Software package page.
- Migration from the previous cosmic-store package and preferences.

## Install

Download `kompas-preview-amd64.deb` and `SHA256SUMS` into the same directory:

```bash
sha256sum -c SHA256SUMS
sudo apt install ./kompas-preview-amd64.deb
kompas
```

The package is a stripped debug preview build, not an optimized production release.
Kompas uses existing repositories and Flatpak remotes. Enable Flathub yourself if
you want its catalog. Zorin Software remains available.

## Validation

The attached package comes from the successful build for the tagged source commit.
CI checks formatting, clippy, workspace tests, replacement of the old package,
AppStream metadata, X11 startup/navigation and the local package page in GNOME Software.
Real-world Zorin testing is still needed.

## Known limits

- Steam discovery uses featured items plus live search, not a full catalog index.
- Epic/GOG game catalogs and a user review system are not implemented.
- Native platform flags and Wayland estimates do not guarantee hardware, Proton,
  anti-cheat or controller compatibility.
- Steam handles purchases and game installation; ownership is not checked.
- Signed APT distribution and inclusion in standard Zorin are future work.
